The live face follows one interactive Cursor CLI (cursor-agent) session: blue with a moving dot means a turn is running, amber means Cursor is waiting for you to approve a command, white means the prompt is idle, and gray means its state is unknown or more than one session matches. The bar lights when your keystrokes would reach that exact session.

Tip: hold the key for ½ second while Cursor is frontmost to capture its project and session. Press to raise its iTerm2 or Terminal window and, under tmux, select its exact pane.

Requires: Automation access for iTerm2 and/or Terminal for the hot indicator, capture, and focusing (macOS prompts on first use). Finding sessions and reading their state needs no permission.

Amber is tmux-only. Cursor writes nothing to disk that separates “waiting for your approval” from “still thinking”, so the only evidence is the terminal itself — which this key can read for tmux-hosted sessions. In a bare iTerm2 or Terminal window an approval prompt shows as blue (running) instead. If a future Cursor release reworks that prompt, amber simply stops appearing rather than start lying — though recognised prompt wording appearing in ordinary output can still, in principle, read as amber.

Cursor’s editor/Desktop sessions are not targets — only the CLI.
